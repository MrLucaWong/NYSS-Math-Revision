核心科學概念：閉合迴路 (Closed Circuit)

為什麼只有「閉合電路」才能讓小燈泡發光？

金屬導線內部充盈著無數可自由移動的微觀粒子——自由電子 ($e^-$)。電池如同「電子推動幫浦」，負極排斥電子、正極吸引電子。只有當電路無任何斷口且正確經過用電器時，電子才能進行持續的單向定向流動！

1. 水管迴路比喻

導體內的電荷就像充盈在封閉水管內的水分子。如果水管中間被切斷（開路），水流就會在出口處堆積堵塞，水泵（電池）便無法繼續驅動整體水流。

  • ▶ 電池（幫浦）：提供驅動電荷移動的「電壓」。
  • ▶ 閉合迴路：電荷必須「有來有回」才能形成持續電流。

2. 電子流 vs 傳統電流

金屬中真正流動的是帶負電的自由電子。電子被電池負極推開、被正極吸引，因此電子流與歷史規定的「傳統電流」方向相反！

⚡ 電子流 (真實移動)

電池 負極 (–) ➔ 外電路 ➔ 正極 (+)

➡️ 傳統電流 (人為規定)

電池 正極 (+) ➔ 外電路 ➔ 負極 (–)

3. 小燈泡雙接點構造

小燈泡內部有兩根支架支撐鎢絲：一根連接到側面金屬螺紋，另一根連接到底部金屬觸點。

關鍵通電規則：

電流必須從一個接點進入、貫穿燈丝，再從另一個接點流出，燈泡才會發光！

挑戰一：側面雙接點陷阱

你的預測：
題目觀察與思考：

從外觀上看，電池的正負極都已經用導線接到了小燈泡上，連成了一個看似完整的圈，小燈泡會發光嗎？

學生常見直覺誤區：
誤以為只要電池正負極都有導線連到燈泡上，算是圍成一個圈就會亮。
科學原理拆解：
小燈泡內部有兩根支架連接燈絲，一根連到側面螺紋，另一根連到底部點。兩根導線都接到螺紋，電流根本沒有通過內部的燈絲！
請先點擊上方按鈕預測：「會發光」或「不會亮」
